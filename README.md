# Простая система инкрементного резервного копирования данных на сервер и восстановления файлов при необходимости

Проект содержит:
1. Bash-скрипт для бэкапа данных на удаленный сервер
2. Bash-скрипт для восстановления данных с вышеупомянутого сервера, ориентируясь на нужную пользователю дату
3. Конфиг файл, нужный для настройки cron

## Требования

- Linux (Ubuntu/Debian/CentOS/Fedora)
- Установленные пакеты: `rsync`, `ssh-client`, `cron`
- Права на выполнение скриптов (chmod +x)
- SSH-ключи между машинами должны быть настроены

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/tonyhaisha/linux-backup-automation.git
2. Выполните настройку конфига
     ```bash
   ./config.sh
3. Настройте переменные внутри backup.sh и restore.sh
